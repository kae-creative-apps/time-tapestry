# Handoff presentation decisions

This is a record and packaging of the existing identity, not a redesign of the app.

| Decision | Source | Role |
| --- | --- | --- |
| Existing Time Tapestry contours, rounded typography and light paper canvas | Current app source at main 079cb6a and Tayloe's supplied references | Primary visual authority |
| Clearly captioned asset specimens in an orderly grid | Fonts In Use, Refero style 470e5fb7-8e29-4b30-acc5-fb2907d86b51, https://fontsinuse.com | Document organization only; no borrowed fonts or colors |
| Large identity specimen with generous surrounding space | Forner, Refero style 5b077981-cc8a-4f93-9bd4-b158984f7215, https://forner.studio | Presentation scale only; no borrowed wordmark, palette or imagery |
| Actual assets carry the visual explanation | Brand guide request and source files | No stock photography or synthetic family examples |
| Current and earlier variants remain visibly separate | Asset and source audit | Prevent accidental substitution of geometry, fonts or palettes |
| Full-repeat, brighter, four-front direction remains a design brief | Tayloe's explicit corrections | No invented approval or silently changed production artwork |

The guide uses current paper #FBFAF8, ink #432E23, white specimen areas and thin warm-gray rules. Rounded display type remains Quicksand. Body is Inter. Patterns are decorative, never text backgrounds with insufficient contrast. The warm palette is documented from the product, not adopted from an unrelated style reference.
