# Time Tapestry designer handoff

Prepared October 6, 2026. Version 1. Product source: GitHub main commit 079cb6a.

Start with `Time-Tapestry-Brand-Guide_v1.pdf` at the top of this package. The matching HTML is editable and uses relative asset paths. Keep the folder structure together.

## What to use

- `01-Logos/Current-app`: current website and product SVGs and transparent PNGs. The horizontal lockup does not include the tagline.
- `01-Logos/Extended-v39-reference`: earlier identity assets, including the vertical signature with its tagline. These differ from the current app geometry and colors. Keep versions separate.
- `02-Fonts`: Quicksand for display, Inter for current app body copy, licensed font files and notices. Manrope is historical; Noto CJK is a book coverage fallback.
- `03-Patterns`: editable thread and interlocking artwork, with current raster derivatives. Earlier gradients are reference material, not the new postcard direction.
- `04-Postcards`: all four current front-and-back proof pairs, individual PNGs, standalone HTML and PDF; plus the earlier complete-repeat reference. Current-review sample QR codes are inactive. Earlier screenshots are visual references only; their QR destinations were not verified. Do not send these sample proofs to a mailing list.
- `05-Motion`: the current production closer and separately labeled joining-hands review sources and preview.
- `06-Source-reference`: relevant source files and provenance for implementation handoff.

## Decisions still needed

The four current postcard fronts are identical. Tayloe requested four related but distinct fronts, less brown, brighter, with a complete, softer pattern, without a pink-and-green treatment. The supplied current proofs are an accurate implementation reference, not completion of that redesign.

The older vertical v39 logo and the horizontal product logo are both supplied. Do not silently replace one with the other or combine their geometry. Bring the selected master back to Tayloe before standardizing a new cross-channel system.

The joining-hands v4 animation is a review source, not the deployed closer. The current closer is clearly labeled separately. No new motion approval is implied.

Current print format is 9 x 6 inches, not the obsolete 6 x 4 format from the early kit. The artwork includes 0.125 inch bleed on every side. These are RGB design proofs, not certified PDF/X or press-approved color separations.

This package contains brand and sample design material only. It contains no customer interviews, real customer mailing addresses, account access links, API keys or production credentials.

## Editing and delivery

Use SVG for scalable vector artwork and PNG for slides or office documents. The wordmarks are outlined; do not recreate them by typing the name. There is no native Illustrator or Figma source file in this package. SVGs import into both.

Save new versions with a new version suffix. Keep original marks and approved files intact. Return editable artwork, SVG/PNG exports, a font/license list and a labeled preview PDF. For print, confirm the printer's current template and color profile before producing press-ready output.

The guide records existing product styling separately from new recommendations. Production operation, provider setup and real delivery verification remain separate from a visual handoff.
