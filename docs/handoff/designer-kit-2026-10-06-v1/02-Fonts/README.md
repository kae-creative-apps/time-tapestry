# Typography files

Current application: Quicksand for display headings, Inter for body copy. The application loads Quicksand weights 500, 600, and 700. For current usage, see the exact layout and Tailwind references in 06-Source-reference.

Quicksand/quicksand.ttf is the full variable source font. The Latin WOFF2 is the current bundled web font. quicksand-print-medium-v1.ttf is the existing static print subset with its own internal family name, Time Tapestry Print, to respect the source font's reserved name. Use the full source font for general design, and keep the static print asset for reproducing the existing renderer.

Manrope is included only to open older v39 documents. It is not the current application body typeface.

Noto Sans CJK SC Regular, Sans2.004, is a story-book character fallback. It is not a brand heading face. Keep its license with redistributed font files.

All font licenses are included alongside their files. Do not replace the outlined logo lettering with typed font text.
