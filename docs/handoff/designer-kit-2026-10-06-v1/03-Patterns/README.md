# Pattern and texture assets

Approved-vector contains the source interlocking stitch pattern and flowing-thread artwork. App-artwork contains existing production raster and vector exports, including the quiet v41 flowing pattern.

Preserve the source shapes. Cropping and low-opacity use are appropriate, but avoid stretching, high-contrast noise behind text, or inventing a new monogram pattern. The earlier v5 complete-repeat postcard reference used 22% pattern opacity. The current v6 postcard export differs; compare both folders before changing production artwork.

Historical-v39-gradients preserves older peach and moss artwork for reference only. It does not approve a pink-and-green postcard redesign.
