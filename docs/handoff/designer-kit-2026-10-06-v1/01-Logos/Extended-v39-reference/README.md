# Extended v39 reference assets

These unchanged assets preserve the older v39 master set, including its primary vertical lockup, outlined wordmarks, monograms, and espresso, walnut, moss, peach, and white variants. They are useful source reference, not a replacement for the current app logo folder.

v39 colors: espresso #3B2A21; walnut #6A5747; moss #868973; peach #B98B74; white #FFFFFF. Current app values and master geometry differ. Treat adoption of an old alternate as a design decision to review.

The existence of peach and moss alternates does not approve a pink-and-green postcard direction. The user's current postcard request is brighter, less brown, with a complete subtle pattern and four distinct fronts. The current four exported fronts remain identical, as documented in 04-Postcards.
