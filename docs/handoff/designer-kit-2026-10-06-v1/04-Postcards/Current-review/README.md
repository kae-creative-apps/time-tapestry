# Time Tapestry postcard review

Open **time-tapestry-four-postcards-front-and-back_v1.pdf** for all four front/back pairs. Individual sides are included as 300 dpi PNG and self-contained HTML. Four paired PNG previews are included for easy viewing.

This is an export of the current quiet-flowing-keepsake-v6 renderer, not a redesign. All four fronts are identical. Each back has a different public message and a QR for its corresponding chapter. The names Evelyn and Anna are fictional; every QR points to example.invalid and cannot open a real collection. The blank lower-right area is reserved for printing-service addressing.

Art size including bleed: 9.25 × 6.25 inches. Trim: 9 × 6 inches. PNG dimensions: 2775 × 1875 pixels.

The exact HTML came from src/lib/collection/postcard-artwork.ts and postcard-design.ts. PDF export used WeasyPrint70, with only zero-margin page dimensions supplied. PNGs were rasterized from those PDFs at 300 dpi. The paired review PDF places the unchanged artwork on a labeled review sheet. Intermediate per-side PDF files were removed to keep this folder compact.

No product code was modified and no printing or email provider was called.
