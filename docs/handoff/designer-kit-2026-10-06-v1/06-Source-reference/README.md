# Source references

App contains exact current design-related source files, copied unchanged. They document color tokens, logo paths, page typography, patterns, and postcard geometry. They are references for working with the application repository, not a standalone app or a printer-ready package. Relative imports outside this selection require the full GitHub repository.

Archive-v39 preserves the older brand presentation, asset sheet, color tokens, and original source-lock notes. The v39 primary lockup is vertical and its dark ink is #3B2A21; the current app lockup places the mark beside the name and uses #432E23. Preserve both source sets and resolve intentional future updates with the brand owner. References in historical notes may point to files in the original archive that are not part of this focused handoff. Do not use historical 6 x 4 print specifications for the current 9 x 6 cards.

No account records, real recipient QR codes, environment files, credentials, private recordings, or application runtime dependencies are included.
