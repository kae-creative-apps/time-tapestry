# Time Tapestry design folder, v39

Start with `presentation/Time_Tapestry_Asset_Sheet_v39.pdf` for an overview, or the editable eight-slide PowerPoint in the same folder.

## Assets

- `assets/logos`: restored woven t icon and primary logo, each in espresso, peach, moss, walnut and white. SVG masters and transparent high-resolution PNG exports.
- `assets/wordmarks`: stacked wordmarks with equal letter size on both lines and the same custom t in all three positions. Outlined SVG masters and transparent PNG exports.
- `assets/patterns`: interlocking tapestry repeat and flowing crossing threads. SVG and PNG.
- `assets/gradients`: three transparent soft gradient circles in the approved palette.
- `print`: 6 x 4 inch postcard front and back, RGB SVG/PNG artwork, PDF review proofs, and 0.125 inch bleed versions.
- `web`: responsive website preview, desktop/mobile screenshots and CSS color tokens.
- `source`: approved screenshots, color tokens, font files and licenses.
- `verification`: source integrity and export checks.

## Using the files

Use SVG for sharp website logos and scalable graphics. Use PNG when an application does not support SVG. White assets are transparent and intended for dark surfaces. Keep the web canvas and postcard writing surface white. Peach is an accent color, not small body text.

The icon was reconstructed from the explicitly approved original screenshot, not from a regenerated brand board. Its silhouette overlaps the screenshot by approximately 99.33%. All color variants use the same four vector paths. This is a consistent reconstruction, not a recovered original vector file. The three wordmark t letters share one glyph, with the icon's separated bar and compact rounded foot treatment.

The palette is espresso #3B2A21, peach #B98B74, moss #868973, walnut #6A5747 and white #FFFFFF. Interlocking and flowing patterns follow the approved board. The flowing thread has been cleaned to remove screenshot texture artifacts.

Slide text and layout are editable. Logo artwork is placed as an image, with separate SVG source assets provided. Install the included OFL-licensed Quicksand and Manrope fonts if you need to use those fonts in new layouts. Wordmark SVGs already contain outlines.

The print files are RGB review artwork, not certified CMYK or PDF/X. Confirm the printer's required format, physical color proof and paper stock before a production run. The website file is a preview, not a live interview or donation service.

Earlier versions remain in the job folder. This folder is the consolidated v39 handoff.
