# Time Tapestry designer kit, v1

Start with the [11-page brand guide](Time-Tapestry-Brand-Guide_v1.pdf). Then read [the handoff notes](00-Start-here/README.md) and [the editable brand brief](00-Start-here/BRAND-VOICE-AND-BRIEF.md).

The [HTML guide](Time-Tapestry-Brand-Guide_v1.html) is editable and opens locally. Keep the folder structure intact so its fonts and images resolve.

- **01-Logos:** SVG and transparent PNG logo sets. Current product and earlier variants are labeled separately.
- **02-Fonts:** font files and redistribution licenses.
- **03-Patterns:** vector artwork and raster derivatives.
- **04-Postcards:** all four front/back review pairs, individual files, editable HTML and PDF, plus the earlier full-repeat reference.
- **05-Motion:** current film closer and separately labeled joining-hands review preview and editable sources.
- **06-Source-reference:** design tokens, implementation references and identity provenance.

These files document the existing identity. They do not approve a new design. Read the guide for the four-postcard redesign brief and unresolved version choices.

Native Illustrator and Figma files are not included. Import the SVGs to use the vector artwork. The film closer MP4 is supplied; its exact editable source is not verified. The joining-hands study has editable source, with setup notes inside 05-Motion.

ASSET-INDEX.json and ASSET-INDEX.csv preserve source provenance for copied assets. FILE-CHECKSUMS.sha256 covers every packaged file except itself. Guide PDFs and HTML were visually checked, and the ZIP was tested for archive integrity.
