# Question-card music

Default file: `question-card-bed.wav`

This bed is an original 70 BPM placeholder: a soft synthesized piano-style arpeggio and a quiet string pad, with no vocals. It was generated for Time Tapestry and is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

It plays only under the five-second interview question card and is faded out before the storyteller’s answer. Swap it without editing the renderer:

- Replace this file, or
- Set `STORY_FILM_QUESTION_MUSIC` to an absolute path of the licensed track Kaelyn supplies.

A film that has already been rendered keeps its audio. The next automatic film version picks up the file that is present when that version is prepared.
