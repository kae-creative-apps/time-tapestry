# Time Tapestry woven logo

The visual source of truth is [../DESIGN.md](../DESIGN.md). This is the native HyperFrames version of the same ten-second motion study authored in Remotion.

Use the approved v39 icon and outlined wordmark geometry from the shared scene without alteration. Paper #fbfaf8 is the canvas; espresso #3B2A21 is the final mark and type. Walnut #6A5747 provides fiber depth, peach #B98B74 and moss #868973 are quiet thread accents only. The tagline uses bundled Quicksand, 40px. No external assets, real photographs, narration, or music.

All layout and choreography come from ../scene.mjs and ../motion.mjs. Run `npm run build` after changing either. Never independently change the generated SVG artwork or timing in index.html.
